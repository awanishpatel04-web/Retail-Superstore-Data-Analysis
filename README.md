# Retail Superstore Data Analysis

## Project Overview
This project analyzes retail sales data to understand sales performance, profitability, customers, regions, products, and shipping modes.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Excel

## Project Workflow
1. Raw data inspection
2. Data cleaning
3. Missing-value handling
4. Duplicate removal
5. Data validation
6. Exploratory data analysis
7. Data visualization
8. Power BI dashboard creation

## Key Analysis
- Sales and Profit by Category
- Sales and Profit by Region
- Sales by Segment and Ship Mode
- Monthly Sales and Profit Trends
- Top Customers
- Top States
- Profit by Sub-Category
- Discount vs Average Profit

## Dashboard
The Power BI dashboard provides interactive analysis using Region, Category, and Segment filters.

## Files
- `Superstore_Raw_Noisy.xlsx` — Raw dataset
- `Retail_Superstore_Cleaned.xlsx` — Cleaned dataset
- `Retail_Superstore_sales_Analysis.ipynb` — Python analysis notebook
- `dashboad power bi.pbix` — Power BI dashboard
